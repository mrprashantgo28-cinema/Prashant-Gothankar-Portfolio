## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `prashant-portfolio`.
2. Upload `index.html`, `README.md`, and the complete `assets` folder (keep the folder structure).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes. GitHub will show your live website URL on the Pages screen.
